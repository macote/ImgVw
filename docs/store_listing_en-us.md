This is the release-owned copy for the initial ImgVw Microsoft Store listing. Partner Center text fields use plain
text; copy the text inside each block without the Markdown fences.

## Product name

```text
ImgVw
```

## Description

```text
ImgVw is a small, fast image viewer built for browsing local image collections on Windows.

Open an image or folder and move quickly through adjacent files with the keyboard or mouse wheel. ImgVw keeps the
interface out of the way and provides display caching for responsive browsing. It can automatically apply EXIF
orientation and uses embedded color profiles when available, with color-management support for JPEG, PNG, and HEIF
images.

Use regular or randomized slideshows on one display or across multiple monitors. Recursive browsing can add supported
images from subfolders when you need to explore a larger collection.

Supported file types: JPEG (.jpg, .jpeg), PNG (.png), HEIF (.heic, .heif, .hif), BMP (.bmp), GIF (.gif), icon (.ico),
and TIFF (.tif, .tiff).

ImgVw works offline. Images are decoded locally on your device and are not uploaded to the developer or a third-party
service. ImgVw is free and open-source software.
```

## Short description

```text
A small, fast, offline image viewer for browsing local images, folders, and slideshows on Windows.
```

## What's new in this version

```text
Start quickly after launching from the Microsoft Store: choose an image or folder from the new welcome screen, or drag
one into the viewer. ImgVw no longer tries to browse the Windows system folder when launched without a file. The new
start screen also follows your Windows light or dark app preference.
```
